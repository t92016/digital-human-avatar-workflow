先選你要做的事

  1. 只看效果：回首頁點選三組示範，直接切換九支完成影片，不需安裝模型。
  2. 部署相同軟體環境：依下方順序安裝固定依賴、檢測硬體，再下載SadTalker。
  3. 重建同一角色或做新人物：還需要角色來源、分層與校準素材。公開MP4可觀看，但不包含可編輯身體圖集；新人物必須先做靜態與嘴型短測。

01 ／ 取得程式與閱讀順序

git clone https://github.com/t92016/digital-human-avatar-workflow.git
cd digital-human-avatar-workflow

依序讀 AGENTS.md、README.md、專案進度.md，再讀相關docs。OpenCode可直接使用repo根目錄的AGENTS.md；其他Agent也可從agent.md開始。專案進度是唯一交接來源。

02 ／ Windows基礎環境

準備Python 3.12、Node.js 22以上、Git與uv。使用專案內的環境，不搬移其他電腦的.venv、node_modules、驅動或快取。

.\scripts\setup.ps1 -PythonCommand python -RenderTools
.\.venv\Scripts\python.exe -m avatar_workflow doctor

setup安裝固定Python／npm依賴，RenderTools取得影音工具與獨立渲染瀏覽器。doctor重新檢測CPU、RAM、GPU、可用資源與候選；候選不代表已通過模型或人物品質測試。

03 ／ 下載已測試的對嘴環境

.\scripts\setup-sadtalker-cpu.ps1

使用獨立Python 3.10.21、CPU torch 2.6.0與固定SadTalker原碼；四個必要權重合計約1.10GiB，由腳本下載並核對SHA256。來源與版本在sadtalker-models.json，不會把權重放進Git。

部分現有入口／狀態
對嘴SadTalker：已有CPU安裝、3～5秒短測及此人物完整原音入口
本機辨識／對齊可選faster-whisper tiny，模型及revision見config/local-alignment.json
新作品語音本機TTS優先，BreezyVoice／Qwen3-TTS尚待介接；目前示範聲音為既有TTSMaker音檔
本機生圖Qwen-Image等仍是候選；先核對硬體、版本及授權，不自動下載所有模型

04 ／ 新人物先做短樣本

先確認照片／卡通、頭像或全身、風格、服裝、主題、動作模式、位置與大小。完整照片預設保留本人造型；指定卡通身體才匹配新頭像。語音確認後才固定時間軸。

.\.venv\Scripts\python.exe scripts/run-sadtalker-head-test.py --image private_inputs/my-character/head.png --audio private_inputs/my-character/voice.wav --output outputs/my-head-test --seconds 4.4

路徑是你自行提供的素材，不是repo內附人物。嘴型／眼鏡／相似度通過後，再校準眼皮、頸部及連續關節，接回教材、字幕與三模式。完整做法與現有專用腳本範圍見另一台電腦操作指南。

品質維持，速度依機器不同。

硬體較弱先使用單worker、batch、CPU、快取與分段；保留已接受素材與成品規格。量化或換模型要重新比較人物效果。Pages不提供伺服器推論，公開repo也不會自動取得其他Agent的生圖工具權限。

05 ／ 驗證與收工

.\.venv\Scripts\python.exe -m unittest discover -s tests -v
npm.cmd test
.\.venv\Scripts\python.exe scripts/verify-publication.py
.\scripts\shutdown-sync.ps1

最後一個命令預設掃描秘密、排除模型及更新收工時間；只有使用者明確要求才提交／推送。repo附有可攜收工Skill。目前完成範圍、實測成本與未完成能力一律以專案進度為準。
