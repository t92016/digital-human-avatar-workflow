## 樣本與範圍

使用 `阿忠小義01.jpg` 左側男生，因腿與鞋清楚；02 的下半身被桌子遮擋。來源原圖未覆寫，01 的 SHA256 為 `EE12F0E37A4A6B1B6433421423E7A58E9465D183439BC93F177F095DD91E7024`。

內建 image_gen 先產生單人、空手透明圖，再產生移除嘴巴線條的內部動畫底圖；第二張僅用於疊加可替換的 SVG 嘴型。制服、角色風格及全身構圖沿用已確認選項。原卡片遮住的身體與雙手屬補繪。提示保存在 `work/round01/`；內建工具未暴露精確後端模型版本，沒有宣稱已鎖定 GPT Image 2.5。

角色保留於左下角，靜止可見高度約 45%。本輪使用暫定 1920×1080 畫布，同一台詞、同一配音、同一字幕比較三種模式；不是新作品的預設構圖。基準位置不移動，模式 2、3 的腿部僅原地抬動／轉動。

台詞：「大家好！我是阿忠，今天要提醒大家：走廊慢慢走，上下樓梯靠右行。看見同學有困難，記得主動幫忙。一起讓校園更安全、更友善！」

## 驗證結果

- Python 11 項測試通過：舊 GPU、忙碌 GPU／RAM、未知架構、多卡不合併顯存、非 CUDA 統一記憶體、離線、字幕字詞不一致、安全路徑、素材包驗證及衝突前不寫入。
- 瀏覽器動態測試通過：三種模式逐 cue 檢查嘴型唯一且匹配、字幕一致、跳轉前後狀態一致、角色根位置固定；模式 1 頭腳不動，模式 2、3 頭腳有不同變換。
- 三個 HyperFrames `check --snapshots` 的 lint、runtime、layout、motion、contrast 均無 error。各有 4 個 Studio 分組結構 warning（教學面板／rig 尚未拆為子 composition），及 1 個透明 PNG 畫布超出活動容器的 warning。已檢視截圖，透明邊界為空，實際人物未被切斷或遮住教材／字幕；這些警告仍留在報告，未以全域忽略關閉稽核。
- 實際 MP4 全部完整解碼，無解碼錯誤；均含 H.264 1920×1080／24 fps 與 AAC 音軌。解碼音訊和原 WAV 零位移相關值均約 0.999719，確認音軌沒有錯置或明顯時間位移。
- 已目視檢查實際 MP4 擷取的手部／活潑動作、樓梯與互助場景畫面，確認繁體字可讀、版面輪替與字幕出現。`outputs/round01/qa/` 保存證據；不是只檢查 HTML 預覽。
- 素材包匯出與相同內容匯入已通過，9 個允許清單素材；原圖、角色輸出、音訊、生成專案、環境與工具均經 `git check-ignore` 確認被忽略。

詳細機器報告及原始日誌位於 `work/hardware/report.json`、`work/round01/`，包含三份 check、動畫驗證、MP4 驗證與渲染 log，均不進 Git。

## 安全查核與相容修正

- Python 依賴隔離於 `.venv`，固定直接與解析後版本；npm 使用鎖定檔與 `--ignore-scripts`，安裝時 audit 0 個已知漏洞。Python 依賴尚未跑獨立漏洞稽核，亦未完成全面原始碼／執行期網路行為稽核。
- Rhubarb 只取官方 release，自行計算 SHA256：`62fa416a8d5e382a3828ee4bef358ce520d0b4cabdeaea75a7ac266d098d1fe3`。上游 release 未提供可獨立比對的 digest，因此只作來源與後續一致性紀錄。
- FFmpeg 9.0.2 封存與供應者公開 SHA256 比對一致：`60f467265b1e312373dbcd92200c2618a74850f98d3d078e94296bb3fa2047ba`。工具來源由 [FFmpeg 官網](https://ffmpeg.org/download.html) 指向 [Gyan builds](https://www.gyan.dev/ffmpeg/builds/)，不是 FFmpeg 專案自行簽署的 Windows 二進位。
- Windows Defender 掃描呼叫失敗（0x80004005），防毒驗證未完成，不能保證沒有惡意程式；未停用防毒或提高權限。
- Rhubarb 在中文 Windows 路徑下失敗：改在本次擁有的 ASCII 暫存資料夾執行官方 binary／資料，輸出驗證後寫回中文專案；暫存目錄限制於系統暫存根。已實測成功。
- 系統 Chrome 在 HyperFrames `--version` 前置檢查失敗，改用官方 Chrome for Testing headless shell。所有持久狀態與快取改放專案 `work/`，不需要修改個人 Chrome 設定。
- 大型下載曾中斷；FFmpeg 改用可續傳的小範圍下載，完整封存完成且公開雜湊一致後才解壓。

## 尚未驗收的品質範圍

配音可用與音軌一致不代表使用者接受口音、語氣與速度；目前設定仍為 `voice_user_accepted=false`、`provisional-test-only`。中文 phonetic cue 是近似嘴型，尚未完成逐音素人工校正；相關值也不能證明嘴型語音學正確。

肢體是這張阿忠的剪裁分層 2D 動畫，沒有生成式身體重建或骨架自動辨識；活潑模式目前是原地肢體擺動，尚未加入屈膝等複雜變形。教學背景為三個腳本相關示意面板，尚非通用腳本自動分鏡／背景生圖引擎。新角色仍須建立 rig 與檢查關節邊緣。
