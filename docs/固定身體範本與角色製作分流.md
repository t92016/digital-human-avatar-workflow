# 固定身體範本與角色製作分流

2026-10-24最新規則：現成全身卡通保留其身體；真人全身照轉Q版時預設保留本人身形、服裝及鞋。半身／大頭要求全身時先找同人全身參考，缺少則確認補繪；不再默認阿忠校服。阿忠第三輪的已驗收身體仍保留為可選範本，使用者指定時才製作配合其畫風的新頭像。完整通用需求見[工作流規劃](通用教學影片工作流與公開發布規劃.md)。

## 每次製作前的選單

1. 確認輸入是大頭照、半身照、全身照或現成角色圖。完整輸入預設保留原身體；只有使用者指定換身體或只要頭像時才另行分流。
2. 提供八種頭像風格：半寫實 Q 版、3D 可愛公仔、黏土、日系動漫 Q 版、美式卡通 Q 版、扁平向量 Q 版、絨毛玩偶、水彩童書。沿用使用者指定的內建生圖能力；工具若不暴露精確模型 ID，不宣稱已鎖定 GPT Image 2.5。
3. 依輸入選「保留原身體／服裝」「只有頭像」「指定阿忠或其他提供的卡通身體」「缺參考經確認後補繪」。既有構圖與服裝決定可沿用，不要求使用者重新選已確認項目。
4. 全身方案再選三種原地動作、位置與大小。舊選擇已確認可沿用，不必每輪重問。
5. 本機TTS為新作品主要開發方向，先確認模型能力與可試聲音；未安裝時不虛構名稱／編號。TTSMaker備援才列既有23款聲線；語音驗收後固定時間軸。真人頭像以原有嘴巴的圖做SadTalker短測，不能按下方歷史SVG範本抹掉嘴。

```powershell
.\.venv\Scripts\python.exe -m avatar_workflow templates
.\.venv\Scripts\python.exe -m avatar_workflow voices
```

## 阿忠校服固定身體

範本 ID 為 `azhong-school-v1`，規格在 `config/avatar-templates.json`。沿用第三輪藍黃運動制服、短褲、白襪、藍鞋、無臂軀幹、完整袖子手臂及肩部重疊圖集。身體素材與動作直接重用，不因頭像風格不同就自行重畫整個身體。若頭身風格差異明顯，先讓使用者看組合預覽；需要改身體才另外取得其明確要求。

素材從私人 `round03_asset_pack.zip` 匯入，或在本機複用 `outputs/round03/character/`。程式及範本規格可放 Git；可編輯人物圖與私有素材包仍不隨 repo 公開，指定的展示成品另放examples。新作品的聲音獨立選擇；新台詞不能沿用阿忠舊字幕時間。只有明確複用同一台詞及同一音訊作換頭測試時，才可一併複用原時間資料。

指定此身體時只製作配合其畫風的新頭像，校準比例、頸部與膚色；原嘴SadTalker為新人物主要路線。下方無嘴PNG／mouth_center僅描述早期SVG示範的重現，不能覆寫阿德已接受嘴型，也不是所有新人物必備。手腳膚色或服裝變體另外確認，不假裝制服即本人服裝。

`video/composition.cjs` 已支援獨立頭像 PNG，頭部可與身體分開取圖。手腳／制服維持原貼圖，嘴型與頭部微幅動作照常運作。以下只是座標格式，實際數值必須依新圖確認：

```json
{
  "rig": {
    "version": "overlapping-shoulder-v1",
    "head_layer": {
      "file": "new-head-mouthless.png",
      "target_rect": [190, 45, 709, 615]
    },
    "mouth_center": [578, 557],
    "mouth_scale": 1
  }
}
```

新 PNG 放在該輪 `outputs/roundXX/character/`；build 會複製到該輪專案。頭像需透明、嘴型槽正確、上下緣適合原頭部剪裁及頸部轉軸。額外頭像的私人跨機素材包須另行擴充允許清單，不將它藏進程式 repo。

需要大頭小身時，在使用者確認比例要求後，以 `rig.body_scale` 與 `body_scale_anchor` 等比縮放完整身體群組，頭像另調 `head_layer.target_rect`。`head_clip_bottom` 可隱藏重複頸部邊線，`neck_bridge` 可補連續短頸，`head_pivot` 控制實際歪頭軸點。這些都是選用設定，預設不改既有範本；不能只將頭與身體各自帶的頸部直接拼在一起。須檢查正面及歪頭中間角度，再由使用者確認外觀。

第五輪已用個人照片做首個新頭像靜態樣本，頭像相似度已接受，組合頸部及大頭小身比例另行檢視。這不等於任意人像自動換頭，或新人物端到端影片已驗證。最新實測及待辦集中於 `專案進度.md`；已驗收的是阿忠身體動作，程式接點測試不代表所有風格的頭身接合都自然。

## 歷史換頭試驗與重現指引

阿忠＋萌萌1202固定示範在 `examples/azhong-mmeng-1202/`。以下是當時換頭試驗設計，保留為歷史重現；後續阿德本人身體13秒整合已另有基準，最新驗收看專案進度。新作品依本文件上方最新身體規則及通用工作流，不再把以下舊試驗順序當未完成工作。

建議準備一張正面、光線均勻、五官與髮型清楚、沒有物品遮嘴的大頭照。照片盡量包含完整頭頂、下巴與少量肩頸；約1024像素以上可作為建議，重點是臉部實際清晰度。只有全身照也可，但需確認頭部仍有足夠細節。選擇固定校服身體時，大頭照即足夠；只有要保留本人服裝／體型或客製身體時才需要全身參考。

1. 使用者把照片放到 `private_inputs/round05/source/`（也可提供其他本機位置），再說明路徑與檔名。沿用照片不代表可公開照片或新成品。
2. 確認頭像風格與身體方案。可從八種風格選一種；首個測試建議選接近阿忠的乾淨 Q 版卡通，配已驗收藍黃校服，較容易觀察接合。這是建議，不代替使用者選擇。
3. 先生成頭像與嘴型疊加用的透明底圖，校準比例、頸部、膚色、嘴型座標，做靜態全身預覽供使用者確認；此時不用重新生成身體。
4. 第一支動態測試建議複用已驗收的13秒台詞、萌萌1202音訊及時間資料，只替換頭像，專看臉部辨識度、接合、嘴型與動作邊界。可沿用左下角45%和三種模式比較，若使用者指定其他構圖則依其選擇。此測試不宣稱在替新人物複製其本人聲音。
5. 頭像接合通過後，請使用者提供新台詞。若要角色自稱新名字，該句也屬新台詞，需重新配音；主動提供23款聲線選單，可沿用已選聲線。驗收新音訊後，重建詞界、字幕、嘴型與背景時點，不沿用阿忠秒數。
6. 再用第二個人物與另一台電腦驗證，整理缺失後才封裝互動Skill。新人物PNG需加入該版本私人素材包允許清單，驗證匯出／匯入，不能只把本機絕對路徑寫進設定。

「讀repo就能觀看成品」「取得素材後能重建阿忠」「新照片可完成整條工作流」是三個不同驗證範圍。目前前兩者已有對應成品與流程；任意新照片的端到端製作、乾淨筆電安裝與完整互動Skill仍需下一階段實測。內建生圖能力與網站取音需可用的工具及互動，單純下載本機依賴不會自動取得這些服務。

## 客製身體

真人全身照預設依本人服裝／體型做專屬Q版，使用者另有指定則照指定造型。缺參考或重新設計先確認服裝、體型、姿勢、風格；再準備完整身體與有重疊的肩部、上臂、前臂、手、腿、腳及軀幹分層。大幅動作不可只裁開皮膚再旋轉。

新的分層素材另立範本版本，檢查中間動作、接縫、遮蓋層級與活動範圍。保留已驗收阿忠範本，讓使用者日後仍能快速選用。

使用者在接受阿德第八輪局部眨眼後，提出先分析「真人全身照→該人物的Q版全身→對嘴／眨眼／手腳動作」，並明確指出這條路線要製作自己的身體與服裝，不是只套阿忠或小義身體。本節是架構與測試建議，尚未生成新人物、重建骨架或產生新全身影片；執行與驗收仍集中於 `專案進度.md`。

### 已驗證與缺口

- 原本已有Q版全身阿忠的三種原地動作與萌萌配音示範；這不是一張真人全身照轉專屬身體的驗證。
- 阿德是個人頭像轉Q版後配阿忠校服身體。第五輪手腳已接受，但使用早期2D嘴型；第六～八輪已接受的SadTalker嘴型／穩定／眨眼仍是獨立頭像，尚未接回動態身體。
- 「新真人全身照、專屬Q版身體服裝、新角色對嘴／眨眼與手腳整合」沒有完整樣本，不能因各模組分別成功就宣稱整條路線已可一鍵完成。

### 可行的方法與依據

工程上值得驗證，建議在現有PC沿用「頭部音訊對嘴＋局部眼皮＋分層身體動畫」的組合架構。可以共用動作時間邏輯，但新角色的身體貼圖、裁切、關節位置、活動範圍與頸部接合須重新準備；不是把阿忠材質換色就視為保留本人全身造型。

已查閱 [SadTalker官方README](https://github.com/OpenTalker/SadTalker) 與本機固定commit `cd4c0465ae0b54a6f85af57f5c65fec9fe23e7f8` 的 [貼回程式](https://github.com/OpenTalker/SadTalker/blob/cd4c0465ae0b54a6f85af57f5c65fec9fe23e7f8/src/utils/paste_pic.py)：官方雖稱full body/image模式，該程式把生成的臉部畫格以seamlessClone貼回固定原圖。據程式判斷，這不會額外生成可控制的抬手、抬腳或屈膝；不能把`--preprocess full`當成全身肢體控制器。本輪只閱讀及分析，沒有啟動該模式重跑。

### 建議的短測順序

1. 先確認全身照片人物、Q版畫風、頭身比例、服裝／鞋子要保留哪些、站姿、用途與三種動作模式。照片宜能看清臉、雙手與雙腳，避免手臂交疊或衣物遮住關節；臉部細節不足時再補同人的近照。
2. 先完成本人專屬Q版全身靜態圖，驗收相似度、髮型、服裝、鞋與比例。被遮擋的背後材質屬生成補繪，不能宣稱還原照片不可見部分。
3. 依已接受全身設計準備頭、軀幹、含袖子的手臂及腿／鞋素材，提供肩部／髖部重疊與必要遮蓋。需要彎肘、屈膝或張掌時再增加對應關節／網格／姿勢素材，不能直接旋轉裁斷四肢。
4. 從同一設計取得足夠清楚的原嘴頭像，先做3～5秒對嘴與局部眨眼；新人物的眼部控制點與遮罩必須重校準，不能直接複製阿德座標。頭部確認後處理去背、頸部、衣領及身體遮蓋。
5. 做3～5秒全身整合短測，先驗證抬手放回、輕抬腳／原地擺動與頭像動態同時正常，再逐步驗證其餘模式。角色留在使用者選定範圍，檢查完整中間過程，不能僅移動整張全身圖或看一張峰值。

主要風險是全身照臉太小、遮擋需補繪、頭身畫風／比例不一、頸部與動態去背邊緣、衣服關節穿幫，以及彎曲關節尚無通用實作。這些是待實測項目，不是現在已發生的新缺陷；未提供新照片前不能預判該人物一定可用。

### 與本機配音階段的關係

原定眨眼驗收後評估本機TTS（BreezyVoice台灣華語方向、Qwen3-TTS備案），尚未安裝或形成四類聲音庫。角色整合和聲音模型是獨立工作；如果優先驗證全身能力，建議先用已接受短音訊作技術對照，避免同時更換人物、身體、聲音和時間軸。正式新人物聲線仍由使用者選擇，不代表複製照片人物本人的聲音。

此為建議調整順序：專屬全身靜態→分層／頭身短測→本機TTS→新台詞字幕與較長影片；使用者尚未選定執行順序。原素材、程式與環境本輪均未修改，無新推論耗時；回復仍直接使用既有round08頭像／阿忠固定示範。
