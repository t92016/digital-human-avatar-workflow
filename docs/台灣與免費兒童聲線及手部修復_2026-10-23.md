# 台灣與免費兒童聲線、手部連續性修復

查證日期：2026-10-23。這是研究、決策與驗證紀錄；最新跨 Agent 狀態集中於 `專案進度.md`。

## 最後採用的條件

使用者要求免註冊、免另外申請 API 金鑰。免費台灣童聲找不到時，接受中國口音，但要增加可選聲線。原先選擇的 VoAI 軒軒保留為未來備選，這階段不要求開帳號或購買。手部修復影片先完成；本輪影片仍使用已有台灣成人男聲雲哲作技術驗證，不冒充兒童配音。

## 免費、免註冊的童聲網站

這七款列於中文清單，沒有台灣口音標示、沒有精確年齡，先作普通話方向候選；不能把它們列成台灣小學生。網站另有台灣通用成人聲音，不能據此認定上述童聲也來自台灣。

免費頁可直接選聲與試聽，不必先登入或申請 API；目前公告每週 20,000 字，個別聲音有單次字數限制與可能的排隊。自訂台詞轉換有圖形驗證碼，本次沒有處理驗證碼，**尚未用阿忠台詞完成這七款合成／下載，也未主觀評比音質排名**。多情感的調節控制有 Pro 標示，不把進階情緒控制列成已驗證的免費能力。免費額度及政策可能改變，以當次頁面為準。[官網免費頁與操作說明](https://ttsmaker.com/zh-cn)

使用方式：中文 → 以名稱或編號尋找 → 先按「試聽音色」→ 選定後輸入台詞 → 完成圖形驗證 → 開始轉換 → 下載 WAV／MP3。不使用分享短連結，不將角色照片上傳此網站。下載的音檔保存在 `private_inputs/voice/` 或新輪次 `outputs/`，再重建嘴型與字幕。

若要無人操作的自動配音，現有 Edge-TTS 可免帳號、免金鑰連網合成。本次重新列出 Edge 可用清單，`zh-CN-YunxiaNeural` 仍是 Cute／Cartoon 男聲；官方未公開兒童年齡。`zh-CN-XiaoyiNeural` 為 Lively／Cartoon 女聲，也不因此算已核實的女童。不可將 Azure 有、但 Edge 當次沒有的聲音直接列為本工作流可用，也不可把成人升調或同聲線速度變體計成新增兒童模型。[Microsoft 官方聲音目錄](https://learn.microsoft.com/en-us/azure/ai-services/speech-service/language-support?tabs=tts)

免費網站是人工選聲入口；目前程式自動配音只有 Edge-TTS，**未實作 TTSMaker 自動控制或 API 介接**。

VoAI 官方有新戶試用點數，但需要帳號，試用音檔有背景音樂、影片有浮水印，不等同免帳號、無限制免費。這是目前查到台灣童聲數量較足的來源，但不符合使用者本階段條件。[官方 API／試用說明](https://www.voai.ai/voai-api)

若未來改採 VoAI，先以帳戶的 `GET /TTS/GetSpeaker` 查實際模型、名稱與風格，再送 `/TTS/Speech`，不把公開頁快照當成 API 權限。公開頁的 Mosa 尚未在本次讀到的 ConnectAPI 文件列為可呼叫版本。只從安全環境變數提供金鑰；本次沒有實際設定或呼叫生成 API。[官方模型清單 API](https://connect.voai.ai/docs/features/voices.html)、[文字轉語音參數](https://connect.voai.ai/docs/features/text-to-speech.html)

在本次查閱範圍，尚未核實「免註冊、免 API、明確台灣口音且有兒童標示」的男童／女童各一至兩款。這不是宣稱網路上完全不存在；不以通用成人台灣聲線、繁體介面或童趣命名補足數量。

## 手部問題與修復

第二輪將截出的皮膚手臂旋轉，衣服袖子仍留在軀幹；大角度時原圖沒有藏在袖口後面的材質，裁切邊與固定袖口露出缺口。只收緊輪廓可以消除碎線，無法修復完整關節。先前檢查通過主要代表時間線、嘴型、字幕及代表點位置，未覆蓋整段肩膀連通性；使用者回報的斷裂是有效的新缺陷。

本次用**內建 image_gen** 補做透明分層圖集：無手臂軀幹、含完整袖子的左右手臂、圓形肩膀重疊材質。原頭部、短褲、腿與鞋沿用既有素材。工具沒有提供可核驗的精確模型 ID，因此不宣稱已指定 GPT Image 2.5；完整提示保存在 `work/round03/arm_torso_atlas_prompt.txt`，來源與 SHA256 在 `work/round03/image-provenance.json`。

結果是 `outputs/round03/character/arm_torso_atlas_v1.png`，1536×1024 RGBA，保留生成 alpha。沒有用程式後製角色點陣圖；由原生 SVG 剪裁圖集並配置層級，GSAP 在固定肩膀轉軸轉動整條「袖子＋手臂」，圓帽藏在連續軀幹後面。生圖用來補素材，實際動畫由 SVG／GSAP 處理；逐幀生圖並不保證手部連續。

三種模式的幅度、抬起 1.05 秒／停留 0.70 秒／放下 1.05 秒、3.80 秒間隔保持第二輪設定。角色左手轉角仍為 95／110／120°，另一手 25／40／55°。模式 1 頭腳固定，模式 2、3 的腳部參數保留；固定左下角、45% 可見高度、不走動。轉軸從舊袖口改到肩膀，因此角度相同不代表手掌路徑與第二輪完全相同。

這仍是單骨段手臂：沒有獨立肘部、手腕、張掌或網格變形。若後續需要彎肘與更複雜動作，可再補上臂／前臂重疊層，或做網格權重骨架；不再直接旋轉裁斷的皮膚區塊。當前 SVG／GSAP 已能在這台 PC 渲染，不需為修復肩膀額外安裝大型 GPU 模型。

先取得第三輪私人素材包；程式 repo 不含人物圖與配音。

```powershell

node scripts/build-sample.cjs round03
$env:AVATAR_TEST_ROUND='round03'
npm.cmd test

node scripts/hf.cjs check samples/round03/mode2 --snapshots

node scripts/hf.cjs preview samples/round03/mode3 --background --port 3019
# 檢查通過後，依本輪授權各自 render mode1、mode2、mode3：
node scripts/hf.cjs render samples/round03/mode3 --quality looks --fps 24 --workers 1 --no-browser-gpu --output outputs/round03/mode3_lively.mp4
.\.venv\Scripts\python.exe scripts/verify-videos.py --round round03
.\.venv\Scripts\python.exe -m avatar_workflow pack --round round03
```

第三輪三支 MP4 實測為 1920×1080、24 fps、15.75 秒、378 幀、H.264＋AAC。手部版／自然版／活潑版約 1.32／2.41／2.48 MB；單 worker 軟體渲染約 35.7／34.4／35.0 秒。完整解碼無錯誤，AAC 與來源 WAV 零位移相關值 0.999810。

每模式取樣 36 張，包含第一個完整抬放週期每 0.1 秒及後面三次峰值，共 108 張。檢查所有取樣的肩膀轉軸不漂移；透明角色 alpha≥100、四鄰域連通分析中，未出現 ≥40 像素的分離零件。這可抓出斷開的大片手臂，但不能證明所有像素、人體自然度或主觀品質。實際連續畫面仍須目視檢查，報告在 `work/round03/arm-continuity-verification.json`。

三個 HyperFrames check 通過；保留既有 Studio 分組／透明畫布邊界 warning。瀏覽器嘴型、字幕、倒轉／跳轉、固定位置及模式差異檢查通過，12 項 Python 測試通過。HyperFrames 從 0.8.186 更新至 0.8.188 並重新檢查；其餘既有媒體工具與依賴沒有新增。素材包增為 10 個允許清單檔，含新圖集，匯出與相同內容匯入通過。尚未推送或上傳。
