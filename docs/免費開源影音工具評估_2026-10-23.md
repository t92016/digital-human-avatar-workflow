## 配音候選

### Edge-TTS：輕量原型候選，需連線

Python 用戶端，使用 Microsoft Edge 的線上朗讀服務；並非離線模型，也不是 Microsoft 官方支援的 TTS API。可在測試時檢查線上聲線清單，確認 `zh-TW-YunJheNeural` 男聲是否仍可使用。公開程式碼可免費取得，但不應推論上游服務永久免費、具有服務保證，或程式授權等同上游語音使用授權。[專案說明](https://github.com/rany2/edge-tts)

已讀取 `setup.py` 與網路模組的部分原始碼；其聲音請求連至 Microsoft 網域。PyPI 專案連結指回同一官方 repo，本次查得套件版本 7.3.1，wheel SHA-256 為 `2a3c79d6235a7a736d681233823ce5492e829b43eb47beae49aa181237a8f9a4`。這些是來源核對，並非完整程式安全稽核。

授權須依實際檔案判讀：`LICENSE` 指出大部分程式為 LGPLv3，只有 `srt_composer.py` 為 MIT；GitHub API 的 `NOASSERTION` 不代表無授權。[授權原文](https://github.com/rany2/edge-tts/blob/master/LICENSE)

### BreezyVoice：台灣華語與注音控制候選

聯發科研究團隊公開的台灣華語語音複製系統，可透過注音改善發音，並支援中英混讀。需要參考聲音；不能將它列成已有固定男女各 5 至 8 款聲線的產品。README 明確說明 CPU 可執行，但尚未量測此電腦的速度。[官方程式庫](https://github.com/mtkresearch/BreezyVoice)、[官方模型卡](https://huggingface.co/MediaTek-Research/BreezyVoice)

程式庫與模型卡標示 Apache-2.0。原始 `requirements.txt` 含多項較舊的固定依賴，以及 Linux 專用 wheel；Windows 不能視為照貼安裝即可完成。後續需在隔離環境整理依賴、核對下載來源，再測參考聲音的性別、授權、口音與發音。星數雖較少，因直接針對台灣華語，仍有評估價值。

### Qwen3-TTS：中英文與聲音設計擴充候選

官方提供 0.6B 與 1.7B 版本，可依版本使用固定聲音、聲音設計或參考聲音。官方 0.6B CustomVoice 模型卡列出 9 種音色與 10 種語言，標示 Apache-2.0。中文支援不等於原生台灣口音；需另測台灣用語與參考聲音。官方主要範例使用 CUDA，不能承諾此顯卡可順利執行；CPU 或量化路線需另查核與實測。[官方程式庫](https://github.com/QwenLM/Qwen3-TTS)、[0.6B 模型卡](https://huggingface.co/Qwen/Qwen3-TTS-12Hz-0.6B-CustomVoice)

## 實作方向建議

1. 現有電腦先做輕量路線：比較可用的台灣華語男聲，確認配音，再以 Rhubarb 等工具產生嘴型時間資料；阿忠需另外製作分層角色與嘴型圖組，才能做三種手腳與頭部動作。
2. 若優先離線台灣華語，先評估 BreezyVoice 的 CPU／Windows 安裝與經授權參考聲音；不因 GPU 不足就宣稱完全無法本機配音。
3. 若有更強 GPU 的另一台電腦，再比較 LongCat Avatar 1.5 與 InfiniteTalk 的短片；不在本機下載巨大模型後才檢查硬體。
4. 雲端試用只能當待查核選項，未承諾免費 GPU 額度、可用性或免帳號。未經使用者明確同意不購買算力或訂閱。
