# 阿忠 × 萌萌 1202 固定示範

使用者於 2026-10-23 觀看後接受聲音與動作，指定保留為未來 GitHub 專案的效果示範。三支 MP4、配音 WAV 與字幕直接複製第四輪成品，未重新生成、剪輯或轉碼。片內原有「試配」文字保留；本目錄的驗收紀錄是之後的使用者回饋。

## 觀看

下載整個目錄後，用瀏覽器開啟 [index.html](index.html)。三個按鈕可比較動作，[voices.html](voices.html) 保留當日 23 款聲音選單，選取選項不會發送配音請求。觀看已完成影片無須 Python、Node、帳號或模型；本頁沒有外部字型、分析程式或網路執行依賴。

從專案根目錄提供本機網頁亦可：

```powershell
python scripts/serve-demo.py --port 3023
```

再開啟 `http://127.0.0.1:3023/`；連結僅在該電腦服務運作期間有效。這個預覽器只服務manifest中的展示檔，綁定本機並支援影片時間軸跳轉；一般`python -m http.server`不提供此處需要的位元組範圍回應。GitHub README 提供預覽圖與三支 MP4 入口；互動 HTML 隨 repo 保存，線上互動頁日後另行部署。本次未建立遠端、推送或部署。

## 凍結與重建

- `manifest.json` 保存驗收範圍、版本、來源輪次、SHA256 與檔案大小。可在專案根目錄執行 `python scripts/verify-demo.py` 檢查完整性；這不是素材授權或主觀品質的自動認證。
- 不在這個版本替換照片、配音或影片。新成果另建版本，繼續保留這份基準。
- `baseline-config.json` 是驗收時的參數快照，供對照；不是新人物的自動綁定設定。
- 本目錄只收錄這次指定的展示成品，不含原始照片、可編輯身體圖集、模型、環境、憑證或本機硬體報告。展示不代表另授予第三方角色素材的再散布授權。
- 要重新渲染或套用身體，先依 [跨電腦工作流](../../docs/硬體自適應與跨電腦工作流.md) 安裝依賴並重跑 doctor，再取得使用者指定的私人 `round04_asset_pack.zip`。原素材包及 speech metadata 保留生成當時尚未驗收的快照，當前使用者驗收以此 manifest 及根目錄 `專案進度.md` 為準。
- 免費網站配音有驗證碼等互動步驟；本示範只使用已生成的萌萌 1202 原音訊，不提供免驗證的自動合成服務。

新頭像的需求與驗證順序見 [固定身體範本與角色製作分流](../../docs/固定身體範本與角色製作分流.md)。新人物、英文配音及其他電腦的生成效果需分別實測。
